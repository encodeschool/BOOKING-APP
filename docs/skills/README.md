# Repository Skills

This folder contains the shared UI/UX skill and supporting artifacts for the Booking App.

## Contents
- `docs/skills/USAGE.md` — how to use the skill and local dev tasks.
- `docs/skills/skill-request-template.md` — prompt template for requesting UI/UX improvements.
- `docs/skills/skill-artifact-template.md` — output template for capturing agent results.
- `docs/skills/ui-ux-checklist.md` — checklist for UI/UX review and implementation.

## Skill registration
- ` .github/skills/ui-ux/SKILL.md` — skill instructions and guidance.
- `.copilot/skills-manifest.json` — manifest for repository-level skill registration.
- `.github/skills/ui-ux/README.md` — skill-specific README.

## Developer workflow
1. Open a frontend component file.
2. Use the UI/UX skill request template from `docs/skills/skill-request-template.md`.
3. Apply the recommendations and mark the checklist items.
4. Run frontend dev tasks from `.vscode/tasks.json`.
