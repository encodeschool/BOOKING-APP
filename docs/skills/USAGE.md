# Skills usage — Booking App

This folder contains repository-level skills and instructions to use them.

UI/UX skill
- Path: .github/skills/ui-ux/SKILL.md
- Manifest entry: .copilot/skills-manifest.json

How to use
1. Open the relevant component or template file in the editor.
2. Ask the Copilot or agent: "Use the UI/UX skill to review [file path] and provide accessibility and responsiveness fixes." Include screenshots or a short description when helpful.
3. The skill will return a checklist and recommended changes. Create a PR with the suggested patch.

Local dev tasks
- See .vscode/tasks.json for preconfigured tasks to run frontend dev servers.

Artifact template
