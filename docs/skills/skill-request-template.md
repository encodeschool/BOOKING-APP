# Skill request template

Use this template when asking the agent to apply the UI/UX skill.

## Context
- Application area: e.g. `apps/admin`, `apps/web`, `apps/mobile`
- Screen or component: e.g. `Login page`, `booking form`, `header navigation`
- Files: e.g. `apps/web/src/components/Header.vue`

## Request
Please review the UI/UX of the above component and provide:
- accessibility improvements
- responsive layout fixes
- semantic HTML or Tailwind utility suggestions
- a prioritized checklist for implementation

Include any known issues and the target breakpoint sizes.
