# UI/UX Review Checklist

- [ ] Verify keyboard navigability for forms and dialogs
- [ ] Ensure color contrast meets WCAG AA
- [ ] Add aria-* attributes to inputs where needed
- [ ] Make layout responsive at small/medium/large breakpoints
- [ ] Replace fixed-width elements with fluid containers
- [ ] Use design tokens (spacing, colors, typography)
- [ ] Prefer Tailwind utility classes when present in app
- [ ] Add unit/integration tests for critical interactions
